# Gwent Music Companion 1.9

Version code: 9.

## Lesson history

- History initially shows up to four term groups. Use **Load more** to add up to
  four older groups; scrolling or collapsing terms no longer triggers more requests.
- Each action searches a bounded number of small date windows. Sparse history can
  show fewer than four groups, and older terms may remain incomplete until further loading.
- Failed or interrupted loads retain completed pages. Retrying resumes the same batch.
- Loaded history remains in memory while its screen's ViewModel is alive. A fresh
  visit or app restart fetches a bounded first batch again; there is no persistent cache.

Users upgrading from before 1.7 should also read the
[notification settings migration notes](1.7.md#notification-settings-after-upgrading).
