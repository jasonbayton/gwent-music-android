# Gwent Music Companion 2.0

Version code: 10.

- Finish loading the selected history terms through their service-provided start
  dates before offering the next batch of up to four terms.
- Keep older groups found during completion buffered rather than revealing them.
- Retry failed date lookups or diary windows without expanding the current batch.
- Report unavailable or inconsistent term metadata instead of silently treating
  partial terms as complete. Ad-hoc lessons without a term ID are labelled **Loaded
  lessons only** and do not block browsing older history.

History remains in memory only; this release does not add persistent caching.
